## 简答题

1. `p2.stride=5` p2 执行
2. 当 $STRIDE\_MIN$ 的进程被执行后，其 $stride$ 可能不再是最小值，新的拥有最小 $stride$ 的进程会被执行，最终 $STRIDE\_MAX$
   的进程也会被执行。最大和最小值的差距不会超过最大增量即 $BigStride / 2$
3. HINT: 负数的补码表示
    ```rust
    impl PartialOrd for Stride {
        fn partial_cmp(&self, other: &Self) -> Option<Ordering> {
            Some((self.0 as i64).cmp(&(other.0 as i64)))
        }
    }
    ```
